0.0.1 Die lokale Grundlage.

Die erste öffentliche Version der Python-API und Kommandozeile für regelbasierte Maskierung. Python 3.11+, ohne Modell und ohne Laufzeitabhängigkeiten nutzbar.

Downloads auf GitHub ↗Quellcode ansehen ↗

Enthalten

  • AHV/AVS, UID/CHE, MWST, IBAN, QR-IBAN und Kreditkarten mit passenden Format- und Prüfsummenprüfungen.
  • E-Mail, Schweizer Telefonnummernmuster, URLs, IP- und MAC-Adressen.
  • Drei Richtlinien, konsistente Platzhalter, lokale Zuordnung und Audit-Metadaten.
  • 36 gezielte Tests, ein kleiner synthetischer Benchmark und experimentelle hybride Schnittstellen.

Noch nicht enthalten

Trainierte Modellgewichte, Trainingsdatensätze, Forschungswerkzeuge und eine validierte allgemeine Erkennung von Namen und Adressen. Der neuronale Adapter verarbeitet standardmässig maximal 256 Tokens ohne Aufteilung langer Texte.

Version 0.0.1 installieren

Mit Python 3.11 oder neuer. Die folgenden Aktivierungsbefehle gelten für macOS und Linux. 

git clone --branch v0.0.1 --depth 1 https://github.com/48Nauts-Operator/bowden-pii.git
cd bowden-pii
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
bowden-pii "Contact mia@example.ch"

Für Windows und die Installation des Wheels siehe README.

Eine frühe Version zur Evaluation.

Die Erkennung kann Werte übersehen oder harmlose Angaben maskieren. Prüfen Sie Ergebnisse und bewahren Sie die Zuordnung der Originalwerte lokal auf. Die vollständige JSON-Ausgabe enthält diese Originalwerte.
