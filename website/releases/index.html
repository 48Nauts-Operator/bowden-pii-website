DEVELOPER PREVIEW18 September 2026

0.0.1 The local foundation.

The first public Python API and command-line release for rules-based redaction. Python 3.11+, with no model or runtime dependencies required.

Downloads on GitHub ↗View source ↗

Included

  • AHV/AVS, UID/CHE, VAT, IBAN, QR-IBAN and card identifiers with applicable format and checksum checks.
  • Email, Swiss phone patterns, URLs, IP and MAC addresses.
  • Three policies, consistent placeholders, a local replacement map and audit metadata.
  • 36 focused tests, a small synthetic benchmark and experimental hybrid interfaces.

Not included yet

Trained model weights, training datasets, research tools, or validated general detection of names and addresses. The neural adapter currently defaults to 256 tokens without long-text chunking.

Install version 0.0.1

Use Python 3.11 or newer. The activation commands below are for macOS and Linux. 

git clone --branch v0.0.1 --depth 1 https://github.com/48Nauts-Operator/bowden-pii.git
cd bowden-pii
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
bowden-pii "Contact mia@example.ch"

For Windows activation and wheel installation, see the README.

An early release for evaluation.
