# Bowden-PII website

The bilingual public website for Bowden-PII, prepared for **bowden-pii.com**.
English lives at `/`, German at `/de/`.

Static HTML, CSS and JavaScript. No package installation or build step is needed.

## Preview

```sh
python3 -m http.server 4188 --bind 127.0.0.1 --directory website
```

Open http://127.0.0.1:4188/ or http://127.0.0.1:4188/de/.

## Publish

The workflow in `.github/workflows/pages.yml` publishes `website/` to GitHub Pages
on changes pushed to `main`. Enable **GitHub Actions** in the repository's
**Settings → Pages → Build and deployment** before running the workflow.

The repository and domain have not yet been published or configured remotely.

After registering the domain, set **Settings → Pages → Custom domain** to
`bowden-pii.com`, then configure DNS and enable HTTPS after certificate issuance.
The `CNAME` file documents the chosen domain; GitHub Actions deployments require
the domain to be configured in the repository settings.

Follow [GitHub's custom-domain instructions](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)
and [Pages workflow documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Maintain

- `website/index.html` and `website/de/index.html`: homepages.
- `website/project.html` and `website/de/project.html`: project guides.
- `website/styles.css`: responsive design shared by both languages.
- `website/motion.js`: local Canvas animation, pause and reduced-motion support.
- `website/site.js`: interactive, precomputed example selector.
- `website/examples.js` and `website/de/examples.js`: outputs generated by the
  Bowden-PII Python engine. The browser does not process user-supplied text.
- `website/sitemap.xml`, `website/robots.txt`, and page canonical links: domain metadata.

Keep both languages in sync. All fonts, scripts and styles are local; the site
has no analytics, cookies, backend, or production dependencies.
